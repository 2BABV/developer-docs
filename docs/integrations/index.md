# Integrations

This section covers how to integrate 2BA data into your systems.

## Available integration methods

| Method              | Best for                                              |
|---------------------|-------------------------------------------------------|
| REST API            | Custom applications, real-time lookups               |
| Data export / feed  | Bulk product data, nightly synchronisation           |
| ETIM classification | Standardised product classification data             |

## Common scenarios

- **ERP integration** — synchronise product data and pricing into SAP, Microsoft Dynamics, or similar
- **E-commerce** — enrich product listings with 2BA catalogue data
- **PIM systems** — import and maintain product content

Select an integration method from the navigation to get started.
